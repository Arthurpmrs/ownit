# Introdução 

O Ownit é uma plataforma de SRL (Self-Regulated Learning) feita para ajudar os usuários a 
melhorar seus hábitos de estudo e alcançar seus objetivos acadêmicos e profissionais.

Nesta documentação, você irá obter informações sobre como funciona a plataforma, como 
utilizá-la e obter o máximo proveito dela.
